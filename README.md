\# LeiloesTDSat



\## Sobre o projeto



O LeiloesTDSat é um sistema desenvolvido em Java para auxiliar uma casa de leilões no gerenciamento de produtos. O sistema permite realizar o cadastro e a listagem dos produtos disponíveis, armazenando suas informações em um banco de dados.



\## Tecnologias utilizadas



\- Java

\- MySQL

\- NetBeans

\- Git e GitHub
